# PyDuel

Двухъязычная игра для учеников: дуэли по Python, тренировки с ботом, рейтинг и история матчей. Интерфейс доступен на русском и казахском.

## Запуск локально

Откройте терминал в папке проекта и выполните:

```powershell
python -m http.server 8000
```

Откройте <http://localhost:8000>.

## Supabase

1. Создайте проект Supabase.
2. Откройте `supabase/SETUP.md` и выполните описанные там SQL-скрипты по порядку.
3. Для включения рейтинга, статистики побед/поражений и истории дуэлей примените миграцию `supabase/migrations/20261010_rating_history.sql`.
4. Настройте разрешённые URL в Authentication → URL Configuration.

В `index.html` разрешён только публичный publishable key. Никогда не помещайте в браузер secret/service-role ключи или пароли.

## Публикация сайта через GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Сохраните настройки. Здесь `index.html` находится в корне репозитория, сайт будет доступен по адресу GitHub Pages после завершения публикации.

## Файлы проекта

- `index.html` — интерфейс, лобби, тренировка, рейтинг и дуэли.
- `ru.json`, `kk.json` — русские и казахские строки.
- `supabase/schema.sql` — схема базы и политики доступа.
- `supabase/migrations/` — SQL-обновления для уже созданной базы.
